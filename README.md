# Snake - By Peezy

This is modern implementation of the classic Snake game using HTML5 Canvas and JavaScript. Features a moving apple, particle effects, and dynamic background colors.

## 🎮 Game Features

- Smooth snake movement with IJKL controls
- Moving apple that tries to escape from the snake
- Particle explosion effects when eating the apple
- Dynamic background color changes
- Increasing difficulty (snake speeds up as you eat more apples)
- Score tracking
- Responsive game over and welcome screens

## 🕹️ How to Play

1. **Starting the Game**
   - Press ENTER or click the "Start Game" button to begin
   - The game begins with a welcome screen showing all controls and instructions

2. **Controls**
   - `I` - Move Up
   - `K` - Move Down
   - `J` - Move Left
   - `L` - Move Right

3. **Game Objectives**
   - Control the snake to eat the moving apple (🍎)
   - Each apple eaten:
     - Increases your score by 10 points
     - Makes the snake longer
     - Increases the game speed
     - Creates a colorful particle explosion
     - Changes the background color

4. **Game Over Conditions**
   - Hitting the walls
   - Colliding with your own body
   - Press ENTER to restart when game is over

## 🚀 Technical Features

- HTML5 Canvas for smooth rendering
- Particle system for visual effects
- Collision detection
- Dynamic difficulty adjustment
- Responsive design

## 🔧 Setup

1. Clone the repository
2. Open the project in a web server
3. Open `index.html` in your browser

No additional dependencies required! The game runs entirely in the browser using vanilla JavaScript.
